# Element independent of shape

The seven tetromino shapes come from a shuffled bag, while the element is drawn at random for every piece, so any shape can be any element. This keeps familiar Tetris geometry and puts all elemental variety into colour and contact. It also leaves room to attach behaviours to elements later.

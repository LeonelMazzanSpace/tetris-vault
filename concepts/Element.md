# Element

Every cell on the board carries exactly one of five elements: fire, water, earth, air or plasma. A piece gets one element at creation (`makePiece`) and every cell of it keeps that element for life. The element is the only attribute a cell has besides its position, so everything elemental in the game is built on it.
